How adoption is accelerating signal innovation

  • Shared data, not shared code. Projects adopt GTSS by reading and writing plain CSV text files, so web apps, mobile apps and analysis tools interoperate with no custom translation.
  • Faster to build. Developers skip the hardest first step, gathering and formatting intersection configuration, and start from a ready-made, documented data model.
  • Each adopter adds value for the rest. A signal configured in one GTSS tool can be reused in another, the same network effect that made GTFS transformative for transit.
  • Open for everyone. Released under CC0, anyone can adopt GTSS without licensing or vendor agreements.
